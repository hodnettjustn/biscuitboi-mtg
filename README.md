# BiscuitBoi MTG Life Counter: Update Files

This repository holds the update files for the BiscuitBoi MTG Life Counter,
made by Biscuit Boy (@BiscuitBoiMTG on Instagram).

To update your counter, go to Settings > UPDATE FIRMWARE on the counter,
or use the install page: https://hodnettjustn.github.io/biscuitboi-mtg/
